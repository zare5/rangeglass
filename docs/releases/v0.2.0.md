This release improves the accuracy of Rangeglass's HTTP Range and download-resume diagnostics and adds Markdown reports for bug trackers.

### Accuracy fixes

- A mismatching `If-Range` returning an empty, short, encoded, or inconsistent full response can no longer pass unnoticed.
- HTTP authentication, rate-limit, and server errors stop the scan and produce an incomplete-check result. An earlier observed protocol/content failure is still reported as FAIL.
- Partial content beyond the observed end is rejected; changed totals in 416 responses are detected.
- Valid contained subsets of a requested range are accepted with a warning.
- A 501 response to suffix syntax triggers one explicit-tail fallback, retaining a warning. The default maximum application body read is 8,200 bytes across up to eight probes.
- Redirect histories include only followed hops.

### Usability

```sh
rangeglass "https://example.com/file.zip" --markdown > rangeglass-report.md
```

Paste the resulting report into an issue. Use your own direct-file URL in the command. The English and Chinese READMEs now include symptom tables, curl error 33, CDN/proxy examples, audience guidance, and FAQs.

JSON remains schema version 1. Findings gain an additive `category` field, and new finding codes are documented. Verdicts for the corrected edge cases change intentionally.

### Downloads

- Windows without Python: `rangeglass-windows-x64.exe` (unsigned console executable).
- Python 3.10+ without installation: `python rangeglass.pyz --demo good`.
- Install the wheel: `python -m pip install rangeglass-0.2.0-py3-none-any.whl`.
- Source, SHA-256 checksums, and bundled-runtime license notices are also attached.

This remains a bounded HTTP/1.1 sample check, not a whole-file checksum, download accelerator, or browser CORS test.
